# RecruitIQ — AI Resume Screener

> Powered by **Llama 3 (Groq)** · **LangChain** · **Streamlit**  
> Built for recruiters who need fast, consistent, AI-driven candidate screening — for free.

---

## Overview

**RecruitIQ** is an AI-powered resume screening tool that helps recruiters evaluate candidates in seconds. Upload a job description and a candidate's PDF resume — the tool returns a **JD match score** and a detailed **ATS keyword analysis**, all powered by Llama 3 running on Groq's free inference API.

No OpenAI credits. No infrastructure costs. Just fast, accurate screening.

---

## Features

### JD vs Resume Match Scoring

- Compares candidate resume content against the job description
- Returns a **match percentage score (0–100%)**
- Breaks down scoring across key dimensions: Skills, Experience, Education, and Responsibilities
- Flags strong matches and critical mismatches with reasoning

### ATS Keyword Checker

- Extracts must-have keywords from the job description
- Checks which keywords are **present**, **partially present**, or **missing** in the resume
- Highlights keyword density and placement (summary, experience, skills sections)
- Outputs a recruiter-friendly keyword gap report

## Quickstart

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/recruitiq.git
cd recruitiq
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Set Up Environment Variables

```bash
cp .env.example .env
```

Edit `.env` and add your Groq API key:

```env
GROQ_API_KEY=your_groq_api_key_here
```

> Get a free Groq API key at [console.groq.com](https://console.groq.com) — no credit card required.

### 4. Run the App

```bash
streamlit run app.py
```

Open your browser at `http://localhost:8501`

## Usage

1. **Paste the Job Description** into the text area on the left panel
2. **Upload the Candidate's Resume** (PDF only) using the file uploader
3. Click **"Analyse Candidate"**
4. View the results:
   - **Match Score card** with a percentage and tier label (Strong / Moderate / Weak)
   - **Dimension breakdown** (Skills, Experience, Education, Responsibilities)
   - **ATS Keyword Table** showing Present / Partial / Missing keywords
   - **Recruiter Summary** — a 3-sentence plain-English verdict generated by Llama 3

## Configuration

You can adjust model settings in `core/scorer.py`:

```python
llm = ChatGroq(
    model="llama3-70b-8192",   # Switch to "llama3-8b-8192" for faster/lighter runs
    temperature=0.2,            # Low temp = consistent, structured output
    max_tokens=1024,
)
```

**Model options on Groq (free tier):**

| Model | Speed | Quality | Best For |
| --- | --- | --- | --- |
| `llama3-70b-8192` | Fast | ⭐⭐⭐⭐⭐ | Default — best accuracy |
| `llama3-8b-8192` | Very Fast | ⭐⭐⭐ | High-volume screening |

## Limitations

- **PDF only** — scanned/image-based PDFs without selectable text will yield poor results
- **Groq free tier** has rate limits (~30 req/min); not suited for bulk screening without throttling
- LLM scoring is probabilistic — treat scores as a **signal, not a verdict**
- Resume parsing quality depends on PDF formatting (avoid heavily styled templates)
